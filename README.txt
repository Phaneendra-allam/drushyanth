DRUSHYANTH DIGITAL MARKETING SERVICES WEBSITE

FILES
- index.html: page content, organised with section comments
- style.css: all design, image sizing, and responsive layout rules
- script.js: mobile menu, About image zoom, and footer year
- assets/: local JPG photos used by the website

HOW TO OPEN
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in Chrome or another browser.

EDITING GUIDE
- Change text, section content, and image filenames in index.html.
- Change colours, spacing, typography, and image dimensions in style.css.
- Change menu and image zoom behaviour in script.js.

The Home hero uses assets/hero-office.jpg. Gallery photos are in assets/.
Google Fonts require an internet connection; local photos are included.
Portfolio example images are illustrative; replace them with approved client work before publishing.
